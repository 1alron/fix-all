# 🚗 FixAll — Платформа для Автосервиса

[![Kotlin Version](https://img.shields.io/badge/Kotlin-1.9+-blue.svg)](https://kotlinlang.org)
[![Compose](https://img.shields.io/badge/Jetpack-Compose-green.svg)](https://developer.android.com/jetpack/compose)
[![Hilt](https://img.shields.io/badge/Dagger--Hilt-orange.svg)](https://dagger.dev/hilt/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**FixAll** — это современное Android-приложение, предназначенное для автоматизации взаимодействия между клиентами и сетью автосервисов. Приложение объединяет в себе удобный клиентский интерфейс и мощную панель администратора для управления бизнесом.

🔗 **Backend проекта:** [Auto Service API](https://github.com/khasanyanovk/AutoService/)

---

## ✨ Основные возможности

### 👤 Для клиентов
- **Управление автопарком:** Добавление и редактирование своих автомобилей.
- **Онлайн-запись:** Выбор услуги, филиала и удобного времени записи.
- **История обслуживания:** Просмотр статусов текущих и прошлых записей.
- **Профили филиалов:** Информация о центрах, контакты и режим работы.
- **Отзывы:** Возможность оставить обратную связь о работе сервиса.

### 🛡️ Панель администратора
- **Дашборд статистики:** Наглядные графики посещаемости, популярности услуг и статусов записей.
- **Управление записями:** Полный контроль над записями клиентов (смена статусов, добавление заметок).
- **Управление услугами:** Создание, редактирование и активация/деактивация услуг.
- **Управление филиалами:** Настройка рабочих часов и информации о сервисных центрах.
- **Работа с клиентами:** Просмотр базы клиентов и их истории обращений.

## 🛠 Технологический стек

Проект построен с использованием актуальных рекомендаций Google по разработке под Android:

- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Declarative UI)
- **Architecture:** MVVM + Clean Architecture
- **DI:** [Hilt](https://dagger.dev/hilt/)
- **Network:** [Retrofit 2](https://square.github.io/retrofit/) & OkHttp 5
- **Image Loading:** [Coil](https://coil-kt.github.io/coil/)
- **Navigation:** Navigation Compose
- **Async:** Kotlin Coroutines & Flow
---

## 📐 Архитектура проекта

Приложение разделено на слои для обеспечения масштабируемости и тестируемости:

1.  **Data Layer:** Реализация репозиториев, API сервисов (Retrofit) и локальной БД (Room).
2.  **Domain Layer:** Бизнес-логика, модели данных и интерфейсы репозиториев (чистый Kotlin).
3.  **Presentation Layer:** UI-компоненты на Compose и ViewModel с использованием Flow для передачи состояний.

## 🚀 Быстрый старт

### Требования
- Android Studio Ladybug или новее.
- JDK 17+.
- Запущенный инстанс [Backend](https://github.com/khasanyanovk/AutoService/).

### Установка
1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/1alron/fix-all.git
   ```

2. Откройте проект в Android Studio.
3. Настройте `BASE_URL` в файле `BuildConfig` (или в `Constants`), указав адрес вашего бэкенда.
4. Соберите и запустите проект.
